# 果蠅邊走邊學：動畫

用全腦連結體模型（MaleCNS）模擬果蠅的「邊走邊學」實驗。網頁上方可以切換兩種版本：**懲罰**（電擊，兩隻果蠅 480 秒的走動過程）與**獎賞**（直接刺激獎賞用的多巴胺神經元 PAM，600 秒，最後多一段 OCT 測試）。網址後面加 `#reward` 會直接開獎賞版。下面先講懲罰版，獎賞版在最後一節。

**線上觀看**：開啟本 repo 的 GitHub Pages 網址。
**在自己電腦看**：下載 `index.html`，用瀏覽器開啟即可（資料已包在檔案內，不需要網路，只有字型需要連線，沒有網路時會改用電腦內建字型）。

## 實驗設定

- 場地 15×15 mm。一個角落 8×8 mm 有 MCH 氣味（全濃度、沒有梯度），其他地方沒有氣味。
- 時間表：訓練前測試 120 秒 → 訓練 4 段各 60 秒 → 訓練後測試 120 秒。
- 訓練時，果蠅走進 MCH 區後，在 0–5 秒內的隨機時點開始被電 1.25 秒；留在區內每 5 秒再一下；走出去電擊立刻停。
- 計分：只算同一角落 5×5 mm 內的時間（面積比例 11%）。
- 左邊是學習打開的野生型，右邊是學習關掉的對照。兩隻都是各組 20 隻裡最接近組平均的。

## 畫面上有什麼

- **場地**：紅底＝MCH 區，虛線框＝計分區，灰線＝最近 3 秒走過的路。被電時果蠅變黃、冒出閃電、外框變黃。
- **S 曲線**：蕈狀體輸出神經元（MBON）的「喜好」讀數，趨近型減遠離型。S 在 0.5 秒內掉超過 1.5，果蠅就有機會掉頭。
- **連接強度**：KC→MBON11/12 的突觸權重。圓點是實際記錄的值：開始時是 1，之後每段結束時記錄一次；段內沒有記錄，所以不畫線。其他隨時間變化的數值（位置、電擊、S、是否在計分區）都是每 0.05 秒的模擬紀錄。
- **各段時間 %**：每段待在計分區的時間比例。

## 結果（各組 20 隻）

| | 訓練前 | 訓練後 |
|---|---|---|
| 野生型 | 12.5% | 2.4% |
| 關掉學習（學習速度設成 0） | 13.0% | 14.2% |
| 打亂接線（接線隨機重排，每顆神經元的連接數不變） | 11.5% | 12.3% |
| 隨機電擊（電擊次數同野生型，時間與位置無關） | 12.6% | 1.8% |

關掉學習與打亂接線都沒有變少：避開需要學習，也需要真實的接線圖。隨機電擊也學會了，因為這個場地只有 MCH 角落有氣味：角落外被電學不到東西，電擊碰巧落在果蠅待在 MCH 區裡（或剛離開 2 秒內，模型裡氣味神經元的活動痕跡約留 2 秒）時，就等於氣味配電擊。所以在這個場地，隨機電擊不能當「沒有配對」的對照。網頁下方「對照組」一節有圖。

## 獎賞版（2026-11-25 加入）

- 場地、時間表、給刺激的時機都和懲罰版一樣，只是把電擊換成直接刺激 PAM 多巴胺神經元（模型裡糖受器的訊號傳不到 PAM，所以不用糖受器）。
- 訓練後測試之後多一段 120 秒的 **OCT 測試**：MCH 拿掉，在另一個上方角落放訓練時沒聞過的 OCT，不給刺激；計分算 OCT 角落 5×5 mm。
- 動畫裡左邊是學習打開的野生型（第 17 隻），右邊是學習關掉的對照（第 35 隻），都是各組 20 隻裡最接近組平均的。連接強度圖改畫 KC→MBON09（獎賞時變化最大的連接）。

| | 訓練前 | 訓練後 | OCT 測試 |
|---|---|---|---|
| 野生型，刺激 8 型 PAM | 12.3% | 23.0% | 21.3% |
| 關掉學習，刺激 8 型 PAM | 13.6% | 14.0% | 13.1% |
| 野生型，只刺激文獻 5 型 | 12.4% | 13.1% | 12.9% |
| 關掉學習，只刺激文獻 5 型 | 13.5% | 13.0% | 12.9% |

只刺激文獻上和糖獎賞有關的 5 型 PAM（PAM02、05、06、07、08）學不會；再加上 PAM12、13、14 才學會（20 隻全部增加）。這三型是看了模型結果才加的，不能當成對真實果蠅的預測。學會的果蠅也大幅偏好沒訓練過的 OCT。
